# YanTrans / Music Sync

Асинхронная утилита на Python для синхронизации локальной аудиотеки с аккаунтом **Яндекс Музыки**.

## Архитектура проекта

Приложение построено по принципу трехэтапного ETL-пайплайна:
1. **Инициализация БД:** локальное промежуточное хранилище SQLite (`aiosqlite`) для хранения метаданных и состояний синхронизации.
2. **Сканирование файлов:** рекурсивный обход папок и парсинг тегов аудиофайлов (`mutagen`) со статусом `pending`.
3. **Синхронизация с API:** поиск найденных треков через `yandex-music` API (`ClientAsync`) и добавление их в плейлист или библиотеку пользователя.

### Статусы жизненного цикла трека
- `pending` — спарсен с диска, ожидает поиска в каталоге.
- `found` — найден в каталоге Яндекс Музыки (записан `yandex_id`).
- `not_found` — трек отсутствует в каталоге сервиса.
- `imported` — успешно добавлен в целевой плейлист.

---

## Стек технологий

- **Python 3.11+**
- **aiosqlite** — асинхронная работа с локальной базой данных SQLite.
- **mutagen** — извлечение метаданных из ID3/Vorbis-тегов аудиофайлов.
- **yandex-music** — работа с API Яндекс Музыки через `ClientAsync`.
- **python-dotenv** — управление переменными окружения.
